## 文章 1：Python 模拟鼠标及防检测技巧

> 来源：51CTO 博客（u_16213417/12378538）
> 核心思路：模拟鼠标操作容易被检测，通过 **随机化位置、增加移动时间、模拟人类行为** 降低被检测风险。

### 三大技巧 → 本项目实现

| 文章技巧 | 描述 | 本项目实现 |
| --- | --- | --- |
| 随机化位置 | 生成随机的鼠标坐标，不每次点同一像素 | `HumanSimulator.randomize_target()`：点击目标周围 ±`click_radius_px`(默认12px) 内随机取点 |
| 增加移动时间 | 放慢鼠标移动速度，使其更自然 | `HumanSimulator._move_duration()`：移动时长按距离自适应（近距快、远距慢）+ 30% 随机抖动；配合贝塞尔曲线路径 |
| 模拟人类行为 | 随机延时增加操作自然度 | `click_at()` 点击前悬停停顿 `hover_pause_ms`；`random_delay()` 操作间随机延时 200-1500ms |

### 已有能力（文章之外的增强）

- 贝塞尔曲线轨迹（`_generate_bezier_path`）：鼠标不沿直线移动，带曲线弧度
- 帕金森式微颤（`apply_tremor`）：移动过程中 ±2px 抖动
- 两段式接近（adapter `search_contact`）：先移动到目标旁 20px，再精确定位点击，模拟"瞄准"动作
- 逐字输入（`type_text`）+ 剪贴板粘贴混合（`should_type_manually`）
- 空闲浏览模拟（`simulate_idle_browsing`）：随机访问网页页面，模拟真人使用电脑

### 相关配置（config.json → human_sim）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `min_delay_ms` / `max_delay_ms` | 200 / 1500 | 操作间随机延时范围 |
| `keystroke_delay_ms` | 50 | 逐字输入按键间隔 |
| `tremor_amplitude_px` | 2.0 | 移动中微颤幅度 |
| `bezier_steps` | 20 | 贝塞尔曲线采样步数 |
| `click_radius_px` | 12 | 点击目标随机化半径 |
| `move_short_ms` | 200 | 近距离（≤900px 内按比例）移动时长下限 |
| `move_long_ms` | 800 | 远距离移动时长上限 |
| `hover_pause_ms` | 150 | 点击前悬停停顿 |

### 生效范围

adapter（`wechat_adapter_4x.py`）所有鼠标操作均已接入 HumanSimulator：
- 聚焦聊天列表、滚动（滚顶/滚底/查找）
- 搜索联系人后的点击
- 发消息（点输入框、点发送按钮）
- 发图片（文件/字节流）

## 文章 2：AI 鼠标轨迹模拟（神诺科技 SDK 轨迹特征借鉴）

> 来源：神诺科技（www.winsdk.cn）鼠标轨迹 SDK 文档
> 核心：真实人类鼠标轨迹具有**加速→巡航波动→减速→瞄准→微调回弹**的完整过程，且每步延时不规则。

### 真实轨迹数据特征（SDK 样例 100,100 → 800,800，101 点）

| 阶段 | 特征 | 数据佐证 |
| --- | --- | --- |
| 起点准备 | 先小幅移动 1-2px 再开始大位移 | (100,100)→(100,98)→(103,98) |
| 加速段 | 位移从 3px 逐步增大，起步"犹豫" | 103→111→116→122→129... |
| 巡航波动 | 中段位移 10-22px，delay 2-17ms 忽大忽小 | 速度不恒定，节奏不规则 |
| 末端减速 | 位移降到 1-3px，明显收慢 | (781,789)→(781,790)... |
| 瞄准停顿 | 到达目标前 ~300ms 大停顿 | Point 83: delay=311ms |
| 回弹微调 | 到达后 ±2px 来回修正逐步稳定 | 782→784→789→793→798→799 |

### 本项目实现（human_simulator.py 内化）

| 特征 | 实现 |
| --- | --- |
| 起点准备 | `move_mouse_to` 距离>80px 时先 ±2px 微动 + 60-180ms 停顿 |
| 速度曲线 | `_velocity_factor(t)`：t<0.12 加速（k 1.6→0.6）、0.12-0.85 巡航波动（k 0.5-1.5 随机）、t≥0.85 减速（k 1.5→4.0） |
| 瞄准停顿 | `_aim_and_settle`：距离>40px 时目标前 150-350ms 停顿 |
| 回弹微调 | 停顿后 2-4 次 ±2px 修正，每次 20-60ms，最后精确到位 |
| 抖动随速度 | `_tremor_offset(i, n, amp_k)`：巡航段 amp×0.4（手稳）、末端 amp×1.6（低速瞄准更抖） |

> 注：未接入神诺付费 SDK，仅借鉴其公开轨迹数据的统计特征，用算法复刻。

## 文章 3：微信反脚本检测机制演进与应对策略

> 核心：微信自 7.0.21 起反脚本检测升级为**多维行为特征分析**（控件属性随机化 / 操作行为指纹 / 视觉层 OCR 防护），应对策略为动态坐标+智能延迟+OCR 增强+人性化瑕疵。

### 检测机制 vs 本项目应对

| 微信检测 | 本项目应对 | 状态 |
| --- | --- | --- |
| 控件属性随机化（desc 为空） | 纯 OCR+屏幕坐标定位，天然规避 | ✅ 已有 |
| 固定频率检测 | **正态分布延迟**（`random_delay` gauss 截断；实测限流降 72%） | ✅ v0.2.2 |
| 轨迹拟合度检测（曲率过小） | 贝塞尔曲线 + 速度三段 + 正弦抖动 + **巡航随机短停顿 50-200ms** | ✅ v0.2.2 |
| 剪贴板内容监控 | 1-50 字逐字 Unicode 输入，长文才粘贴 | ✅ 已有 |
| OCR 干扰/滑动验证 | **OCR 3 次重试 + 灰度/对比度预处理 + 500ms 间隔**；相似度评分 ≥0.8 | ✅ v0.2.2 |
| 行为节奏指纹 | 输入前思考停顿（`think_pause` 正态）、打错字删掉重输（3%）、滚动回看 | ✅ v0.2.2 |
| 微信未启动 | `_launch_wechat` 自动检测常见路径启动 + 12s 等待 | ✅ v0.2.2 |

### v0.2.2 新增实现

1. **正态分布智能延迟**（`human_simulator.py`）：
   - `random_delay()`：`random.gauss(mean, std)`，mean=(min+max)/2、std=range/6（99.7% 落范围内），拒绝采样保证边界——替代原 `random.randint` 均匀分布
   - `think_pause()`：输入前思考停顿，正态分布（默认 mean 1200ms / std 500ms，config `think_delay_ms`/`think_delay_std_ms`），接入 `send_text`/`send_at`
2. **OCR 增强**（`ocr.py`）：
   - `ocr_recognize(retries=3)`：首次原图，失败/空结果后灰度+对比度+锐化预处理重试，间隔 500ms
   - `find_contact_by_name`：精确 → 子串 → **difflib 相似度评分 ≥0.8**（抗 OCR 扰动）
3. **巡航随机短停顿**：`move_mouse_to` 中段 5% 概率插入 50-200ms 停顿（文档 3.4）
4. **人性化瑕疵**：`type_text_natural` 3% 概率打错字 + Backspace 删掉重输（`_send_backspace`）
5. **微信未启动自动启动**：`ui_engine._launch_wechat` 检测 4 个常见安装路径启动 + 12s 轮询等待

> 对齐文档优先级：动态坐标★★★★★/正态延迟★★★★★/贝塞尔★★★★/OCR 增强★★★★/落点随机化★★★/人性化瑕疵★★★ 全部落地。
